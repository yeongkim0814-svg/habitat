# habitat (가칭)

회전 원통 거주구를 배경으로 한 3D 1인칭 인디게임. 거주구역에서는 주민과의 일상과 요청을, 오염구역에서는 회피 중심의 PvE 레이드와 격자 인벤토리 파밍을 한다.

- 설계 결정과 로드맵: [My-1st-Ai-office/projects/habitat](https://github.com/yeongkim0814-svg/My-1st-Ai-office/tree/main/projects/habitat)
- 엔진: Godot 4 (GDScript)
- 에셋은 이 저장소에 넣지 않는다(비공개 에셋 저장소에서 관리, 출처 장부 필수).
- 라이선스: 미정. 지정 전까지 모든 권리 보유.
